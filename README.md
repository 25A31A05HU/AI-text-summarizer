# 🌟 AI Text Summarizer

An advanced, client-side extractive text summarizer web application designed to instantly condense complex study materials, lecture notes, and textbook paragraphs into concise, digestible points. Built in alignment with **Sustainable Development Goal 4 (Quality Education)** to make learning resources more accessible and efficient.

---

## 🚀 Features

- **Smart Extractive Summarization:** Analyzes document structure using frequency hashing and sentence scoring to extract the most important information.
- **Customizable Summary Length:** Choose between Short (2 sentences), Medium (4 sentences), Detailed (6 sentences), and Comprehensive (8 sentences).
- **Redundancy Filtering:** Utilizes the Jaccard Similarity index to prevent repetitive sentences, ensuring a smooth and diverse summary.
- **Natural Narrative Flow:** Automatically re-orders selected sentences back to their original chronological sequence.
- **Stunning UI/UX:** Features a dark neon glassmorphism aesthetic with custom background styling, glowing gradient buttons, and responsive grid layouts.

---

## 🛠️ Tech Stack

- **HTML5:** Clean, semantic document structure.
- **CSS3:** Modern styling with CSS variables, Flexbox, backdrop-filter glassmorphism, and responsive design.
- **JavaScript (ES6+):** Core algorithm implementation including Hash Maps, Heap/Priority Queue simulations, and Jaccard similarity calculations.
